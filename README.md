# Hangman Haven

Create a complete Hangman game using Python.

Requirements:

1. Use Python as the programming language.

2. Create a simple and user-friendly Hangman game.

3. Store at least 30 words in a word list.

4. Select a random word from the list for each game.

5. Display the hidden word using underscores.

   Example:      

6. Allow the player to enter one letter at a time.

7. Check whether the guessed letter exists in the secret word.

8. If the guess is correct, reveal the letter in its correct position.

9. If the guess is incorrect, reduce the number of remaining attempts.

10. Give the player a maximum of 6 incorrect guesses.

11. Display the Hangman drawing using ASCII characters after each wrong guess.

12. Keep track of all letters already guessed and prevent duplicate guesses.

13. Display the remaining attempts after every guess.

14. Display "You Win!" when the player correctly guesses the entire word.

15. Display "Game Over!" when the player runs out of attempts and reveal the correct word.

16. Ask the player whether they want to play again after each game.

17. Include a score system:

    - +10 points for winning

    - 0 points for losing

18. Add different categories such as:

    - Animals

    - Fruits

    - Countries

    - Technology

19. Let the player choose a category before starting the game.

20. Use functions to keep the code organized and beginner-friendly.

21. Add comments explaining the important parts of the code.

22. Handle invalid input, such as numbers or multiple characters.

23. Make the game run completely in the Python terminal without requiring external libraries.

Provide the complete Python code and briefly explain how each major part of the program works.
